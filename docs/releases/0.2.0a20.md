DX Talker 0.2.0a20 clarifies alpha release branding and publication navigation.

The shared desktop header and About text now identify the app as Alpha instead of a platform specific pilot. GitHub Actions calls the publication workflow Build and publish DX Talker. The README and release guide link directly to its manual run page. Opening the link does not start publication.

The existing Pilot update channel continues receiving alpha and other prereleases. Installer filenames, download formats and the Ubuntu, Windows, XP and Android functionality from a19 are retained.
