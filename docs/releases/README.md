Modern Windows releases offer x64/x86 installers and portable packages. Starting with a17, separate XP 32 bit and XP 64 bit pilot installers are prepared for acceptance testing. Earlier XP source kits are limited developer tools, not the full application. From a18, the same release page also offers DXTalker-Android.apk for manual installation. Candidate Android test APKs remain artifacts in the [Android APK workflow](https://github.com/Liberty-Chris/DX_Talker/actions/workflows/android-apk.yml). Choose a successful main run, download DXTalker Android debug, extract the ZIP and install app-debug.apk. GitHub sign in is required for artifacts.

From a19, DXTalker-Ubuntu-amd64.deb is the Ubuntu Intel/AMD desktop package. See [Ubuntu setup](../help/ubuntu.md).

Retain published tags and downloads when correcting release text.
