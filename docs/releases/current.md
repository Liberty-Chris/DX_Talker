DX Talker 0.2.0a7 makes cluster profile management clearer and compacts Source and Audio / PTT.

Select a profile to edit its name and connection details, then choose Save changes. New profile and Save new profile create a separate entry. Delete profile removes only the selected entry after confirmation. Both profile selectors stay in sync. The former 100 profile cap is removed; there is no fixed count limit. Profile management no longer depends on unrelated unfinished radio edits.

The credential option now reads Remember password or token on this PC. It saves the password or HTTPS bearer token encrypted for the current Windows account when the profile is saved. Leaving it unchecked keeps the credential session only. It does not create a new secret key.

Source uses compact profile and connection groups, shows only the selected connection type's fields and retains password Show/Hide. Audio / PTT groups outputs, PTT, timing and levels. Serial port and polarity controls appear only for serial PTT methods. Output coordination, device routing, timing and volume behavior are unchanged.

Future certificate handling alignment for macOS, Linux, iOS and Android remains planned. Native trust currently applies to the Windows updater.
