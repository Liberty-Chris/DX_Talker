DX Talker 0.2.0a11 makes mobile listening easier and adds band, mode and activity filters on Windows and Android.

Android now has permanent Listen, Clusters and Settings navigation, working Back behavior, restored form drafts and audio controls on every page. Speech format uses selectable sections and reorder buttons. Light, Dark, System and High contrast appearance choices are included. Filtering and announcement changes apply without reconnecting. Profile selection switches an active session; saving a profile does not start a connection.

Choose bands, modes including FT8 and CW and activity tags including POTA, SOTA and FOTA without typing cluster commands. Uncertain mode remains Unknown. Untagged activities cannot be identified reliably. Filters apply to received data; they do not change saved server filters. Comments remain excluded from speech and disk logs. Updated QR and file transfers include these choices; update Android to 0.2.0a11 before importing a new transfer. Older transfer documents remain accepted.

TCP keepalive is enabled on both platforms. Quiet-feed status is separate from a disconnected feed, and a lack of spots does not force reconnects. Application-level idle commands are not sent automatically. Android background listening, Bluetooth, accessibility and device behavior still need physical operator acceptance.
