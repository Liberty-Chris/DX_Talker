DX Talker 0.2.0a16 adds automatic desktop performance checks to build verification.

Source, portable Windows packages and installed copies are checked for UI startup, tab switching, scrolling and idle CPU use before publication. Measurements and budgets are included in Windows verification reports. A failed budget blocks packaging or publication. These checks run only in explicit self test mode, with synthetic settings and no cluster connection, audio playback or RF transmission. Normal application use does not run the benchmark.

The a15 correction to rounded desktop rendering is retained. Preconfigured clusters are available under Source, Cluster directory, Add selected cluster. Enter your callsign and connect when ready.
