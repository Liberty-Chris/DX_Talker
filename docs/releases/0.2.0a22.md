DX Talker 0.2.0a22 unifies desktop live display and announcement admission.

A new live row is shown only after the same final decision accepts it into the speech queue. Mode, band, activity, license and location rules, age, duplicates, muted spot volume, stopped output and queue capacity are decided before display. Newly received spots while output is stopped do not enter the live list. Start local listening or RF to admit new live rows.

A neutral marker beside the callsign means pending. A green check means playback completed. A red check means an admitted announcement did not complete, with a clickable explanation. Enter or Announcement details opens the selected row's status. Cancellation, faults, queue expiry, filter changes and Catch up to live produce explicit reasons rather than silent skips. Receiver hold and required IDs remain respected; playback is not guaranteed to be heard at a remote radio.

Rejected spots opens a separate bounded session review with red checks and reasons for incoming reports excluded before admission. It does not put rejected reports into the announcement list. The raw Source console is collapsed by default and labelled unfiltered diagnostic traffic. Manual sample previews have a separate window.

The desktop Modes picker offers All modes, including unknown, Known modes only and None, with individual checkboxes reflecting the real selection. Changes save immediately. The all modes choice removes only the mode restriction; band, activity, license and location selections still apply. Existing saved mode choices are preserved. CW inference ranges are unchanged and remain documented operating practice classifications rather than exclusive legal allocations.

The shared desktop behavior applies to Windows, XP and Ubuntu. Android listening behavior is unchanged in this desktop followup. Installer names and the existing update channels remain intact.
