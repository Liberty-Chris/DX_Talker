# Operating DX Talker

## Daily operation

Choose a cluster profile, then Connect. Selecting or editing a desktop profile leaves the current session alone. Connect switches to the entered connection details. Matching spots appear with audio off. Listen locally enables audio for new spots. Mute silences local announcements while the list continues updating. Unmute receives a green hover and keyboard focus treatment in every desktop theme. It announces new arrivals without replaying muted history.

Local volume is beside the live queue and is remembered automatically. Volume zero is shown explicitly. Local audio and RF can run together using separate speakers and radio audio devices. Enable either one first, then the other. While RF is enabled, the local button reads Monitoring RF and mirrors each transmitted spot and ID. Local mute and volume affect speakers only. Unmute joins the next transmission without replaying a backlog. Disable RF preserves local listening. Enabling RF waits for any current local clip to stop before starting the required identification. Stop all output cancels current work and pending switches. It never asks for confirmation.

The main toolbar contains connection, local audio, RF and Filters. Preview selected operates on the selected row. Spot details explains that row's result and recent exclusions. Spot a station and Spot myself remain directly visible on the main page. More actions retains sample previews, clear view, immediate ID, cluster commands and announcement diagnostics. Catch up to live drops queued spot announcements while preserving current audio and required identification.

## Saving and unfinished edits

Appearance, text size, local device and volume, speech delivery, announcement format, history preferences and update preferences save automatically when valid. Listening filters also save automatically. An invalid field stays visible and leaves its previous valid value active. Other valid preferences can still save. The footer reports saving, saved or a specific error; invalid ordinary fields receive a red border.

Radio output devices, PTT, receive monitoring, transmit timing, radio levels and station identification are one radio configuration. Their unfinished edits are saved as a draft. Apply radio changes waits for output cleanup and applies that group together, leaving RF disabled. Enable RF remains a separate deliberate action. Merely editing a radio field does not stop or change active operation. Restart restores the draft without activating it.

Named cluster profiles and listening presets still have explicit save actions because they are reusable configurations. Selecting a listening preset loads it immediately. Replacing or removing a desktop preset offers Undo. Removing a desktop cluster profile offers Undo and leaves an active session connected. Unfinished desktop profile edits are retained between profiles and noncredential drafts survive restart. Passwords and tokens are excluded from draft persistence and transfer.

## Scoped actions

Connect validates connection details only. An unfinished radio or speech field cannot prevent connection. A local preview uses its relevant displayed settings without applying unrelated source or radio edits. Previewing while locally listening mutes the local session and waits for current audio to stop; the user can Unmute afterward. Previewing while RF is active stops RF and never enables it again automatically.

Choose a local output in Audio / PTT. If it is also the radio output, the screen reports that local audio may key VOX. Preview actions do not repeatedly ask the same routing question. Preview uses the selected local destination. A missing device still stops affected output; the app never substitutes another output.

## Setup and troubleshooting

Filters has its own destination at every window size. Compact Live spots retains the applied filter summary. When larger text makes tabs too wide, a page selector provides access to every screen. An empty live list explains whether a source is needed, reports are awaited or current filters exclude arrivals.

Announcements links directly to Speech and Speech links back to format settings. The example and local preview reflect the selected format. System default is an explicit voice choice. Recorded voice labels hide storage identifiers. Generate or resume a recorded voice offers an explicit Resume previous generation action. Use this voice saves the completed selection automatically.

Audio / PTT includes a receive level meter with the configured threshold marked. Test receive input before using receive hold. IDs validates a selected WAV locally and labels the CW or policy interval separately from the independent voice interval.

Maintenance separates Updates, History and Diagnostics. Unavailable update actions are disabled until their prerequisites are ready. Install and restart is the final application action; it stops output and launches the verified installer without another approval dialog. Setup may still require normal operating system interaction. Diagnostic export reports success inline. Help formats headings and links and provides a local text search.

## Android

Theme and announcement choices save automatically. Test announcement uses the current valid saved format. Invalid edits show a persistent explanation. Page scroll positions and drafts survive activity recreation. Each edited cluster has a separate draft. Saving an actively selected cluster updates its connection configuration; while running, the action is labeled Save and reconnect.

Mute discards current and queued speech and does not queue muted arrivals. Pause holds current and incoming announcements for Resume, subject to the existing queue and age limits. Both keep the feed connected. Stop listening closes it. Changing filters reevaluates retained matching rows instead of emptying the whole list. All choices appear selected when All is effective; None explicitly clears a category.

The QR camera stays open between collection pages and shows progress. Closing preserves scanned pages. A complete collection opens one review screen with an Import action. No profile is imported from an incomplete or invalid collection. Imports retain existing profiles and exclude credentials. Profile removal offers Undo. Android still uses system speech and does not add RF or paid online speech.
