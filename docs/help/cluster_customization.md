# Cluster configuration

Use [What do you want to hear?](listening_filters.md) for local band, mode, activity, license and location filters. No cluster commands are needed for these choices. Desktop and Android main spot views show matching reports. Desktop All received exposes retained reports for troubleshooting.

App filters can only select reports the cluster sends. They do not undo saved filters on the cluster account or silently change preferences used by other programs. Source activity and the visible manual command field remain available for reading cluster replies and sending commands when necessary. Syntax varies between DXSpider, AR Cluster and other servers. Consult the connected node's help before changing its settings.

The bundled directory includes W1NR, DX Spots, N2WQ, WB3FFV, W3LPL and W4MYA from the supplied validated operator list. It supports active and retired records, review dates and connection details without credentials. Geographic command examples can be added as they are verified. Desktop Cluster directory and Android Browse recommended clusters show the installed list. Load directory file replaces that list without deleting saved profiles or connecting automatically. Only active entries can be added. Saved profiles can be edited or removed independently.

[Share a DX spot](spotting.md) provides a direct submission form for the current cluster. Self spotting remains subject to the node and event policies.

TCP keepalive maintains transport health. It is not a cluster command or proof of application sign in. There is no universal automatic cluster heartbeat command, and a quiet feed is not itself a connection failure.
