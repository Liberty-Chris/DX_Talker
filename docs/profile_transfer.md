# Profile transfer and curated directories

DX Talker transfer version 1 is a UTF-8 JSON object with schema `dxtalker-transfer`, version 1, profiles and filters. Profile entries contain name and connection only. Connection contains source_type, host, port, login, feed_url and poll_seconds. Filters may contain min_khz, max_khz, max_age_seconds, repeat_seconds, spacing_seconds and frequency_unit. Canonical frequency filters remain in kHz.

Desktop QR transfers contain the selected saved profile plus current filter settings. File exports contain all saved profiles. No stored password, bearer token, protected blob, radio configuration or logging path is included. Query strings in feed URLs are rejected for transfer because they may contain credentials. Enter any private URL parameters separately on the destination. Login callsigns, hostnames and filter preferences are intentionally visible to anyone who can read the QR or file; only share it with the intended operator/device.

QR text uses `DXT1:` followed by unpadded URL-safe base64 of zlib-compressed JSON. QR input is limited to 1800 bytes; decoded JSON is limited to 64 KiB and must finish without trailing compressed data. Large collections use file transfer rather than several ambiguous partial QRs. Readers validate the complete document before any writes. Unknown keys, credential fields, unsupported versions and invalid connection/filter values are rejected.

In Android, use Manage cluster profiles, then Scan desktop QR or Import profile file. Review profile names and destinations and confirm Import. Existing profiles are kept; duplicate names get an import suffix. Imported credentials are blank. Import does not start a connection or select a destination automatically. Imported filters are used on the next listener start. Selecting a cluster stops the current listener before loading another connection. A camera is optional because file import is also available.

The curated directory format uses schema `dxtalker-directory`, version 1 and an entries array. Each entry contains a stable id, name, connection, status (`active` or `retired`), checked (review date as text) and description. The repository's initial entries array is empty while Dad prepares the list. Do not invent active feeds or infer reachability from an old review date. Cluster directory lets the operator load a newer directory file and add an active connection with one click. Already saved connections are not duplicated. Retired entries cannot be added. Existing operator profiles are never removed automatically; Delete profile remains an explicit confirmed action.
